## 验收标准

依据用户指定的[官方图像生成指南](https://developers.openai.com/api/docs/guides/image-generation#generate-animated-gif-output)：向生成端点发送准确模型、`output_format=gif`、帧数、每帧时长、每帧尺寸及共享配置；接收可解码的真实多帧 GIF，并验证请求控制是否落实到产物。模型列表出现名称不能证明实际调用了该模型。

工作台还需保留全部帧与原始时序，正确处理混合静态输出，保存后可恢复，下载字节一致，并正确显示服务拒绝或参数偏差。

| 商品展示 / Sunburst | 9 × 150ms / 512×512 | 309×309，16 × 320ms，486520 字节 | 129.2 秒 | 时序、尺寸均不符 |

前四次均 HTTP 200，均返回一个 GIF 和一张静态 PNG（请求数量为 1）。图标项从实际工作台发起，返回一个 GIF 和两张静态辅助图；浏览器完整完成了保存、封面解码及原件下载，下载与 IndexedDB 原件逐字节一致。五个 GIF 均由 Sharp 完整解码，分别包含 12、16、9、9、12 个不同画面，均设置无限循环。抽取首、中、末帧检查，角色有明显表情变化，中文字可读且星星位置变化，灯笼具有摆动及明暗变化；图标首帧为蓝色圆环。商品画面变化较小，不能只用“帧不同”认定视觉旋转质量合格。

场景和中文两项同时在提示词中写了 9 帧、200ms；其时序吻合不能作为参数字段被解析的独立证据。中文提示词也写了 512×512，尺寸仍未满足。未将提示词补写当作原生参数支持的替代方案。

### 服务端原因

检查运行容器内的实际代码，`/app/services/protocol/openai_v1_image_generations.py` 读取通用图片字段并构造 `ConversationRequest`，没有接入 `frame_count`、`frame_duration_ms`、`complexity` 的原生转发。输出收集函数会同时返回 GIF 与静态辅助图。

运行版本的 `_image_model_settings` 对图片模型别名使用配置的默认上游对话模型；因此请求分别写 Flare、Sunburst，不能证明底层分别执行了对应的 2.6 图片模型。当前测试验证的是该服务能产出 GIF，尚未验证准确原生模型及全部控制项。

## 8090：失败与根因

地址：`http://127.0.0.1:8090/`。运行镜像：`weishaw/sub2api:latest`，版本 `v0.2.19`，源码 revision `dece26153621959ccd7635814f4b2d08304e681a`。

实测角色、商品、场景，并在工作台浏览器中复测角色。排查过程依次发现：

1. 原 OpenAI 分组未开启图片生成，返回 HTTP 403。
2. 临时开启图片生成后，账户未配置 2.6 模型映射，返回 HTTP 404；一次映射刷新期间返回 HTTP 503。
3. 临时添加两个准确的 2.6 映射后，Sunburst 商品、Flare 场景及浏览器角色请求均收到 HTTP 400：`GIF output is not enabled for the model 'gpt-image-2-codex'.`

对照[部署 revision 的实际源码](https://github.com/Wei-Shaw/sub2api/blob/dece26153621959ccd7635814f4b2d08304e681a/backend/internal/service/openai_images_direct.go)：

- `usesCodexDirectImages` 显式列表截至 2.5，未包含 2.6。因此添加账户映射仍会落入旧 Responses 转换路径。
- 同文件的原生 Images 请求构造也没有接入帧数、每帧时长或 complexity；仅新增模型名称不足以完成修复。
- [请求解析结构](https://github.com/Wei-Shaw/sub2api/blob/dece26153621959ccd7635814f4b2d08304e681a/backend/internal/service/openai_images.go) 同样未拥有上述 GIF 字段。

这属于服务端适配缺口。前端传参已在浏览器请求中核对，未把 2.6 映射成 2.5，也未让 8090 绕路请求 3001。不能通过修改前端标签宣称两个服务独立通过。

**临时配置已恢复并查询确认**：分组图片开关恢复原 false，仅移除本次新增的两项 2.6 映射；未覆盖账户刷新后的其他凭据或其他配置。凭据未写入代码、报告或截图。
